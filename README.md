# دليل سمر

موقع عربي يجمع القاعات في مكان واحد، بتصميم يركز على الجوال.
هذه النسخة تشمل آخر تعديل: التصفية حسب المنطقة وعدد الضيوف.

## الرفع على GitHub

فك ضغط الملف وارفع محتوياته إلى جذر المستودع، بحيث يكون ملف index.html في المستوى الأول بجانب مجلد assets.
الموقع ثابت ويعمل على GitHub Pages أو أي استضافة تدعم HTML وCSS وJavaScript، ولا يحتاج إلى بناء أو تثبيت مكتبات.

## التشغيل المحلي

بعد تثبيت Node.js، افتح الطرفية داخل مجلد الموقع وشغّل:

```sh
npm start
```

ثم افتح: http://127.0.0.1:4173

## الملفات الرئيسية

- index.html: الصفحة الرئيسية.
- app.js: البحث والتصفية والمفضلة والمقارنة.
- data.js: بيانات القاعات.
- hall-1.html: صفحة القاعة الأولى.
- hall-details.js: تفاصيل الأقسام والسعة والمرافق والخدمات.
- hall-slideshow.js: عرض الصور المتحرك.
- assets: الصور والخطوط والشعار وفيديو المقدمة.

المفضلة محفوظة في متصفح الزائر، والمقارنة محفوظة خلال جلسة التصفح. التواصل والتنسيق يكون مباشرة مع إدارة القاعة.
